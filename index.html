A manifesto

The agentic AI frontier requires ownership of the agent’s code.

01 Agent as a Code

Agent as a Code means the agent is source you own: versioned, reviewed, and changed like any other code — not a configuration trapped inside someone else’s platform.

02 The frontier

The agentic AI industry did not exist a couple of years ago. Everyone in it — vendors and builders — is still experimenting. Write your own agents if you want to be on the frontier. That is how you try a new idea while the field is still finding its shape, and how you build what you need rather than what a vendor’s product surface allows.

03 Wrappers

There are many agentic platforms and tools. Those products are wrappers. Under the forms, the catalogs, and the run button sits an agent SDK: the loop, the tools, and the state where behavior is actually defined. The frontier requires your own opinion, not an implementation of someone else’s.
